Indexing the inbox query

Step 1

Indexes are a promise about the questions you will ask. A compound index on user and date answers the inbox query in a few milliseconds, but it does nothing for a search across every word in every page.

pnpm install
pnpm test

Step 2

Full text search on a single node is better than its reputation. With sensible weights on titles and notes, and a cap on how much body text you index, it stays quick well past a few thousand documents per person.

Step 3

Postgres and Mongo are both fine choices for a small product. The interesting decisions are about what you index, what you denormalise, and which queries you refuse to support because they would be slow forever.

pnpm install
pnpm test
