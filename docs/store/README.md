# Store listings

The App Store and Chrome Web Store listing text, translated: one file per language, each with `appStore`, `screenshots` (the captions on the App Store screenshots) and `chrome`. Paste them into the language's listing in App Store Connect and the Chrome Web Store dashboard. English is `en.json` (the source the others follow) and `apps/extension/store/listing.md`. `app-store.md` has the iPhone launch: field counts, screenshots, the featuring nomination, the promo video and the launch posts. The glossary for each language is in `docs/i18n/`.
