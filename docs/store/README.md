# Store listings in other languages

The App Store and Chrome Web Store listing text, translated: one file per language, each with `appStore`, `screenshots` (the captions on the App Store screenshots) and `chrome`. Paste them into the language's listing in App Store Connect and the Chrome Web Store dashboard. English lives in those dashboards and in `apps/extension/store/listing.md`. The glossary for each language is in `docs/i18n/`.
