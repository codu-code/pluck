三月的时候，你摘下过一份慢烤番茄米粒面的食谱，30 分钟那个。你知道你摘过，但就是找不到。

你的 AI 找得到。给它一个链接，它就能读你整个 Pluck 资料库：标题、你的笔记、你的标签、你的清单，以及 Pluck 留下的每个网页的正文。

![向 AI 工具提的一个问题，答案来自一个 Pluck 资料库。](/blog/ask-your-ai-what-you-plucked/hero.png)

## 这里面没有 AI

Pluck 从不自作主张，把你摘下的东西发给模型。没有东西会背着你被打上标签，也不会冒出什么摘要。

你连上你的 AI，它才进来，你让它做什么它就做什么。它通过 MCP 连接，这是 AI 工具接入各种 App 用的开放标准。Pluck 支持 MCP，所以任何支持它的工具都能连：Claude、ChatGPT、Cursor，还有其他的。

## 连接它

每个工具用的都是同一个链接：

```
https://getpluck.io/mcp
```

- **Claude。** 进入“设置”，再进入“连接器”。选择“添加自定义连接器”，粘贴链接。接好之后，网页版、桌面版和手机上都能用。
- **ChatGPT。** 进入“设置”，再进入“连接器”。选择“创建”，把链接粘贴为 MCP 服务器 URL。你需要一个支持自定义连接器的套餐。
- **Claude Code。** 在终端里一行命令，见下方。
- **Cursor。** 进入设置，再进入 MCP。用这个链接添加一个服务器。

```
claude mcp add --transport http pluck https://getpluck.io/mcp
```

第一次连接时，每个工具都会让你登录 Pluck，仅此而已。[连接你的 AI](/connect) 里有同样的步骤，还有复制按钮。

## 然后就问吧

- “我摘过哪些关于里斯本的东西？”
- “整理一下我的 Pluck 收件箱。”它会从你已有的标签里给每个条目建议标签，再建议保留、稍后还是归档。你一次性同意，或者改掉。
- “做一个关于酸面包的阅读清单，最好的放前面。”它会搜索、阅读，按顺序建一个清单，每条附一句为什么放进来。在你另作决定之前，清单一直是私密的。
- “根据我这周摘下的东西，给我三个博客选题。”它会完整读最好的五篇，起草三个角度，并附上来源。
- “帮我做每周回顾。”就是周一那封邮件，换成一场对话，一次只做一个决定。
- “把这个摘为笔记：问问 Aoife 安装师傅的事。”它会作为笔记进入你的收件箱。

## 它做不了什么

- 删除任何东西。Pluck 不给它这个权限。
- 把清单公开。只有你能，在 Pluck 里的那个清单上操作。
- 创建你没让它建的标签，或者重命名你自己建的标签。
- 改变清单的用途。

它建的每个标签和清单都带有“由 AI 添加”标记。如果你不满意它某一周打的标签，在设置里点一下，就能把这些标签全部撤回。

![一个由 AI 工具创建的 Pluck 清单，带着陶土色的“由 AI 添加”标记。](/blog/ask-your-ai-what-you-plucked/marked.png)

## 断开连接

设置 > AI 工具 > 断开连接。它立即停止，不用等到会话结束。

## 运行你自己的 Pluck

自托管，但没有公网地址？在设置里生成一个 API 密钥，在本地做桥接：

```
npx @pluck/mcp --server https://pluck.your.host --key pk_live_…
```

你会得到同样的工具和同样的提示词，只是指向你的服务器。

这里面没有 AI。用你自己的。
