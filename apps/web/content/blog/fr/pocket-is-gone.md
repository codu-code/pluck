Mozilla a fermé Pocket en juillet 2025. L’app est partie en premier, et la fenêtre d’export s’est refermée en octobre.

Si vous avez téléchargé votre CSV à temps, vous avez chaque lien que vous avez jamais mis dans Pocket. Un seul fichier, qui dort dans Téléchargements.

Pluck prend ce fichier tel quel.

![Des lignes d’un CSV Pocket qui deviennent des éléments dans Pluck.](/blog/pocket-is-gone/hero.png)

## Le faire venir

1. [Connectez-vous à Pluck](/signin). Vous recevez un lien par e-mail. Pas de mot de passe.
2. Ouvrez les Réglages, puis Import et export.
3. Choisissez Pocket (CSV) et déposez le fichier.

C’est tout. L’import tourne en arrière-plan, vous pouvez donc fermer l’onglet.

## Ce qui vient avec

- Chaque lien, avec son titre.
- Vos tags. Pocket les collait avec une barre verticale, Pluck les sépare à nouveau.
- La date à laquelle vous avez gardé chacun pour la première fois, pour que l’ordre ait toujours un sens.

Si vous avez déjà cueilli quelque chose qui est aussi dans le fichier, vous obtenez un élément, pas deux.

## Où ça arrive

Dans les Archives, marqué Importé. Pas dans la boîte de réception.

Deux mille choses non lues dès le premier jour, ce n’est pas un nouveau départ. Elles sont toutes dans les Archives, toutes trouvables par la recherche : ressortez-en une quand vous en avez envie. La boîte de réception, c’est pour ce que vous cueillez à partir de maintenant.

![Les Archives de Pluck après un import, chaque élément marqué Importé, avec la boîte de réception vide.](/blog/pocket-is-gone/archive.png)

## Les pages

Un CSV Pocket contient des liens, pas des pages, alors Pluck retourne lire chaque page. Il le fait quelques-unes à la fois, pour qu’une grosse bibliothèque ne martèle le site de personne. La plupart des pages reviennent sous forme de texte propre, lisible dans Pluck.

Certaines, non. Si une page ne s’ouvre plus, Pluck affiche « Impossible de lire cette page. » et propose la copie Wayback, pour que vous voyiez quand même ce qu’il y avait.

Désormais, Pluck garde la page quand vous la cueillez, pas seulement le lien. Si le site disparaît, votre copie reste.

## Pourquoi ça n’arrivera pas deux fois

Pocket a fermé parce que Mozilla a décidé de le fermer. Rien de ce que ses utilisateurs auraient pu faire n’y aurait changé quoi que ce soit.

Pluck est open source. Le code est public, et vous pouvez [faire tourner votre propre copie](/open-source) avec une seule commande. L’export marche dès aujourd’hui : chaque élément en JSON, plus un fichier Markdown pour chaque élément et chaque liste. Si un jour nous arrêtons, vous, vous continuez.

## Pas seulement Pocket

Le même écran accepte un zip Omnivore, un CSV Raindrop et le fichier de favoris qu’exporte votre navigateur. Importez-les tous. Ce qui figure dans deux fichiers devient un seul élément.

Puis cueillez la suite depuis le [menu Partager de l’iPhone](/iphone), [Chrome](/chrome), vos e-mails ou [votre IA](/connect).

Cueillez. Triez plus tard.
