3月に、じっくり焼くトマトのオルゾーのレシピをPluckしました。30分でできるほうです。Pluckしたのは覚えているのに、見つかりません。

お使いのAIなら見つけられます。リンクをひとつ渡せば、Pluckのライブラリ全体を読みます：タイトル、メモ、タグ、リスト、そしてPluckが残したすべてのページの本文。

![AIツールへの質問に、Pluckのライブラリから答えている。](/blog/ask-your-ai-what-you-plucked/hero.png)

## ここにAIはありません

Pluckが、Pluckしたものを勝手にAIモデルへ送ることはありません。知らないうちにタグが付くことも、要約が現れることもありません。

お使いのAIは、接続したときに入ってきて、頼んだことをします。接続にはMCPを使います。MCPは、AIツールがアプリにつながるためのオープンな標準です。PluckはMCPに対応しているので、MCPに対応したツールならどれでも接続できます：Claude、ChatGPT、Cursorなど。

## 接続する

リンクはどのツールでも同じです：

```
https://getpluck.io/mcp
```

- **Claude**：設定 →「コネクタ」。「カスタムコネクタを追加」を選んで、リンクを貼り付けます。一度追加すれば、Web、デスクトップ、モバイルで使えます。
- **ChatGPT**：設定 →「コネクタ」。「作成」を選び、MCPサーバーのURLとしてリンクを貼り付けます。カスタムコネクタを使えるプランが必要です。
- **Claude Code**：ターミナルで1行。下にあります。
- **Cursor**：設定 →「MCP」。リンクでサーバーを追加します。

```
claude mcp add --transport http pluck https://getpluck.io/mcp
```

最初の一度だけ、それぞれのツールでPluckへのサインインを求められます。それだけです。[AIと接続](/connect)にも同じ手順があり、コピーボタンも付いています。

## あとは聞くだけ

- 「リスボンについて、何をPluckした？」
- 「Pluckのインボックスを片付けて」。すでにあるタグの中からタグを提案し、アイテムごとに、残す、「あとで」、アーカイブのどれにするかを提案します。そのまま承認するか変えるか、まとめて一度で済みます。
- 「サワードウの読書リストを作って。良いものから順に」。検索して読み、順番どおりのリストを作り、それぞれを選んだ理由を一行添えます。リストは、指示するまで非公開のままです。
- 「今週Pluckしたものから、ブログのネタを3つ」。特に良い5件を最後まで読み、出典付きで3つの切り口を下書きします。
- 「週次レビューをして」。月曜のメールを、会話で。ひとつずつ決めていけます。
- 「メモとしてPluckして：取り付け業者のことをAoifeに聞く」。メモとしてインボックスに入ります。

## できないこと

- 何かを削除すること。Pluckがその権限を渡していません。
- リストを公開すること。公開できるのは本人だけで、Pluckのリストから行います。
- 頼んでいないタグを作ること。自分で作ったタグの名前を変えること。
- リストの目的を変えること。

AIが作ったタグとリストには、すべて「AIによる」の印が付きます。1週間分のタグ付けが気に入らなければ、設定からワンタップでそのタグを取り消せます。

![AIツールが作ったPluckのリスト。クレイ色の「AIによる」の印が付いている。](/blog/ask-your-ai-what-you-plucked/marked.png)

## 接続を解除する

設定 →「AIツール」→「接続を解除」。セッションの終わりを待たず、すぐに止まります。

## 自分でPluckを動かしている場合

公開アドレスのないセルフホスト環境なら、設定でAPIキーを作り、ローカルでつなぎます：

```
npx @pluck/mcp --server https://pluck.your.host --key pk_live_…
```

同じツールと同じプロンプトが、自分のサーバーに向けて使えます。

ここにAIはありません。AIは持ち込みで。
