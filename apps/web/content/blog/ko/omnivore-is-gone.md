Omnivore의 호스팅 서비스는 2024년 11월에 문을 닫았어요. 팀은 다른 회사로 옮겼고, 사용자에게는 데이터를 빼낼 시간이 2주 정도 주어졌어요.

제때 내보냈다면 zip 파일이 있을 거예요. 잘 두세요. Omnivore에 담아 둔 것 대부분이, 링크만이 아니라 페이지 그 자체로 그 안에 들어 있어요.

![Omnivore zip을 펼치니 페이지가 통째로 나오고, 그중 하나가 Pluck 리더에 열려 있다.](/blog/omnivore-is-gone/hero.png)

## zip 안에 있는 것

Omnivore 내보내기 파일은 메타데이터 파일이 든 폴더예요. 담아 둔 것 대부분은 HTML 페이지로도 들어 있어요.

이게 지금 중요해요. 그 사이트 중 일부는 옮겨 갔거나, 바뀌었거나, 사라졌어요. 그래도 내 zip에는 그때 그 내용이 남아 있어요.

## 가져오기

1. [Pluck에 로그인하세요](/signin). 이메일로 링크가 와요. 비밀번호는 없어요.
2. 설정 > 가져오기와 내보내기를 여세요.
3. Omnivore (zip)를 고르고 파일을 끌어다 놓으세요.

가져오기는 백그라운드에서 돌아가니까 탭을 닫아도 돼요.

## 같이 오는 것

- 모든 링크와 제목.
- 라벨은 태그로.
- 각 항목을 담은 날짜.
- zip에서 바로 읽은 페이지 본문. 이건 Pluck이 사이트에 다시 가지 않으니까, 사이트가 사라진 페이지도 온전히 들어와요.

zip에 페이지가 없는 것은 Pluck이 몇 개씩 나눠서 페이지를 다시 가져와요.

## 어디에 들어가나요

보관함에, 가져옴 표시를 달고 들어가요. 페이지 본문까지 전부 검색할 수 있어요. 수신함은 새로 뭔가 담을 때까지 비어 있어요.

## 오픈소스로는 부족했어요

Omnivore는 오픈소스였는데도 사라졌어요. 코드는 공개된 채로 남았지만 서비스는 남지 않았고, 직접 운영하는 건 하나의 프로젝트였어요.

그러니 코드 공개는 절반일 뿐이에요. 나머지 절반은 이거예요.

- **직접 운영은 명령어 하나면 돼요.** [저장소](/open-source)에서 `docker compose up -d`. 웹 앱, iPhone 앱, 내 AI 모두 내 서버로 작동하고, Chrome 확장 프로그램은 명령어 하나만 더 치면 내 서버용으로 빌드돼요.
- **내보내기는 지금 작동해요.** 모든 항목이 메모와 하이라이트까지 담긴 JSON으로 나오고, 항목마다, 리스트마다 Markdown 파일도 하나씩 나와요.
- **Pluck은 링크만이 아니라 페이지를 담아 둬요.** 담는 순간 담아 두니까, 다음에 어딘가 문을 닫아도 가져가는 게 적어요.

## Omnivore만이 아니에요

같은 화면에서 Pocket CSV, Raindrop CSV, 그리고 브라우저가 내보낸 북마크 파일도 받아요. 전부 가져오세요. 두 파일에 다 있는 건 항목 하나가 돼요.

그다음엔 휴대폰, Chrome, 이메일, [내 AI](/connect)로 다음 걸 담으세요.

사이트가 사라져도 여기 남아 있어요.
