# Pluck

A URL saver that keeps the page and lets you organise by hand. Any AI tool reads and organises the library through the connector; the app itself has no AI.

## Capture

**Pluck**:
The act of putting something into your library, from any surface. "Plucked" is the confirmation.
_Avoid_: Save, bookmark, clip

**Re-pluck**:
Plucking a URL that is already in your library. It brings the existing Item back to the Inbox; it never makes a second Item.
_Avoid_: Duplicate, re-save

**Item**:
One plucked thing. Link Items have a URL and a kept page; Notes, Todos and Things are Items with no URL.
_Avoid_: Save, bookmark, entry, card

**Kind**:
What an Item is: Read, Watch, PDF, Image, Note, Todo or Thing. "Links" is the group of Read, Watch, PDF and Image.
_Avoid_: Type, category

**Kept page**:
The copy of a page's text and HTML stored with a link Item, so it survives the original going away.
_Avoid_: Snapshot, cache, archive copy

## Organising

**Status**:
Where an Item sits in triage: Inbox (untriaged), Later (kept on purpose), Archived (finished, let go or expired) or Done (Todos and Things).
_Avoid_: State, folder

**Tag**:
A short label you made. A Tag your AI made carries a "by AI" mark until you touch it.
_Avoid_: Label, category, smart tag

**List**:
A named, ordered group of Items with a purpose line. Each Item in a List has its own note and tick, which belong to the List, not the Item. Private or Public.
_Avoid_: Collection, folder, board, playlist

**Public page**:
The read-only, logged-out view of a Public List at `/@handle/slug`.
_Avoid_: Share page, unlisted link

**Shared List**:
A List its owner shared with particular people by email, See only. They read it as its Public page shows it, from Lists, Shared with you, after signing in with that email; only the owner changes it.
_Avoid_: Collaborator, member, invite

**Handle**:
A user's public name. Everyone starts with a made-up one (plucky-puffin-42) until they pick their own.
_Avoid_: Username

**Highlight**:
A quote from a link Item's kept page, with an optional note.
_Avoid_: Annotation, clip

## Letting go

**Touch**:
Anything that shows an Item is still wanted: creating, opening, editing, tagging or adding it to a List. Expiry counts from the last Touch.
_Avoid_: Activity, view

**Expiry**:
Moving untouched Inbox (and optionally Later) Items to the Archive after the user's chosen number of days. Items in any List are exempt. Nothing is deleted.
_Avoid_: Cleanup, auto-delete, purge

**Archive it all**:
The one-off bulk version of Expiry the user runs by hand.
_Avoid_: Clear inbox, bankruptcy

**Bin**:
Where a deleted Item waits 30 days before it is gone for good. Only reachable from web and iOS, never from your AI.
_Avoid_: Trash

**Digest**:
The weekly rule-based email: what will expire, what is due, the oldest Inbox Items, idle Lists.
_Avoid_: Newsletter, summary, recap

## Connecting

**Connector**:
The MCP server that lets the user's AI tool read and organise their library.
_Avoid_: Integration, plugin, API
